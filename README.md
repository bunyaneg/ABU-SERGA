# ABU SERGA — Digital Historical Exhibition

Interactive presentation website for the Church of Saints Sergius and Bacchus (Abu Serga), Old Cairo.

## Included
- Hero / introduction
- History and identity
- Holy Family cave section
- Architecture
- Saints Sergius & Bacchus
- Timeline
- Image gallery
- Official Matterport virtual tour
- Sources section
- Responsive Arabic-first design

## Research basis
The first version uses information cross-checked against:
- Egypt's Ministry of Tourism and Antiquities — Discover Egypt's Monuments
- State Information Service — Holy Family Journey
- State Information Service — Virtual tour of Abu Serga Church

## GitHub Pages
After enabling GitHub Pages from the repository's **Settings → Pages** and selecting the `main` branch / root folder, the site can be served from:

https://bunyaneg.github.io/ABU-SERGA/

## Important
Some gallery images are externally hosted for the prototype. For the final academic version, replace them with your own photographs or appropriately licensed images and add image credits.
